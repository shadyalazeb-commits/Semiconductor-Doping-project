README — Semiconductor Doping Calculator

This project calculates electron (n) and hole (p) concentrations in doped semiconductors.
It determines the material type (n‑type, p‑type, intrinsic), majority/minority carriers, and charge neutrality.
The program also provides graph plotting, PDF reporting, and CSV loading through a full GUI.

How to Install Requirements
Before running the project, install dependencies by running:

pip install -r requirements.txt

How to Run the Program
Run the main Python file using:

python semiconductor_doping

A GUI window will appear where you can:
• Enter ND, NA, ni
• Compute n and p
• Plot a graph
• Export a PDF report
• Load CSV data

Notes
• Enter scientific notation correctly (example: 1e15, 5e14, 1.5e10).
• Do NOT use: 1×10¹⁵ or 10^15
• Python must be installed on the device.
